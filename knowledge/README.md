# Chatbot knowledge base

These files are the only thing the metrifield.com "Ask us" assistant knows. Each `## heading` becomes one retrievable passage; the assistant answers only from matched passages and refuses everything else.

How to update: edit a file, commit and push to `main`. Cloudflare rebuilds the site and the assistant picks it up within a couple of minutes. Keep passages short and factual; put questions visitors actually ask in `06-faq.md` phrased the way they'd ask them. Do not include anything we are not comfortable stating publicly (grants, unsigned customers, cover levels not yet in place).

Copies of these files are mirrored as Google Docs in Drive → "Metrifield" → "Chatbot knowledge" for the founders to read and comment on; the repo remains the source of truth.
